# Valley Switching Boost PFC PCB Design

## Project Overview

This project documents a four-layer printed circuit board (PCB) design for a Valley Switching Boost Power Factor Correction (PFC) circuit. The project materials were developed as part of electronics engineering work involving PCB design and hardware documentation.

## Project Documentation

The repository preserves the available project files:

- **Project Presentation:** Original PowerPoint presentation documenting the project.
- **Bill of Materials (BOM):** Excel spreadsheet containing component information, footprints, designators, manufacturer part numbers, and other recorded procurement details.

## Design Tools

- KiCad
- Copper CAM

These tools were used in the original PCB design workflow.

## Available Files

| File | Description |
|---|---|
| `Valley_Switching_Boost_PFC_BOM.xlsx` | Available Bill of Materials spreadsheet |
| Original project presentation (`.pptx`) | Project documentation and available design details |

## Design File Availability

The original editable PCB design files, including the native KiCad project, are not currently available in this repository. The available presentation and BOM are preserved for technical reference and portfolio documentation.

## Purpose

This repository demonstrates my exposure to PCB design documentation, component selection, and electronics hardware development.

**Note:** This repository contains recovered project documentation and component data; it does not represent a complete, editable PCB design package.
